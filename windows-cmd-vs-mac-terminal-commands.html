Windows CMD vs macOS Terminal: Essential Commands Side by Side

The command line looks intimidating at first, but it is one of the fastest ways to manage files, test a network and fix problems on a computer. Windows and macOS each have their own command line, and the commands are different. If you switch between a Windows laptop and a Mac, or support users on both, you need to know both sets. This guide shows the most useful Windows Command Prompt (CMD) commands and macOS Terminal commands side by side, with practical examples and safety tips.

How to open the command line

On Windows: press the Windows key, type cmd and press Enter. For tasks that change the system, right-click Command Prompt and choose Run as administrator. Windows 11 also includes Windows Terminal, an app that can hold CMD and PowerShell in separate tabs.

On macOS: press Command + Space, type Terminal and press Enter, or open Applications, then Utilities, then Terminal. Modern macOS uses the zsh shell, which is Unix-like, so many commands match the ones used on Linux servers. If you work with servers, my guide to essential Linux commands will feel familiar.

Key differences to know first

  • Paths: Windows uses backslashes and drive letters such as C: and D:. macOS uses forward slashes and a single file tree that starts at the root folder, with your home folder written as ~.
  • Options: Windows commands usually take switches with a slash, such as dir /a. macOS commands use a dash, such as ls -a.
  • Case: Windows commands are not case-sensitive. On macOS, commands and options are: ls works, but LS does not.
  • Spaces: if a file or folder name contains spaces, wrap it in quotes on both systems.
  • PowerShell: Windows also has PowerShell, a more powerful shell that understands aliases such as ls and cat. This article focuses on classic CMD.

Example 1: Set up a project folder

On Windows, run the following in Command Prompt:

cd %USERPROFILE%
mkdir projects
cd projects
type nul > notes.txt
dir

On macOS, the same job looks like this:

cd ~
mkdir projects
cd projects
touch notes.txt
ls -la

Both versions move to your home folder, create a folder called projects, enter it, create an empty file and list the contents.

Example 2: Troubleshoot a slow or broken internet connection

Network commands are where the command line really shines. Work through these steps in order:

  1. Check that you have an IP address with ipconfig on Windows or ipconfig getifaddr en0 on macOS. On a Mac, Wi-Fi is usually en0, but yours may differ.
  2. Ping a public IP address, such as ping 8.8.8.8. If this works, your internet connection is fine.
  3. Ping a domain name, such as ping google.com. If the IP address works but the name fails, the problem is DNS.
  4. Flush the DNS cache with the command from the table and try again.

Note that Windows sends four pings and stops, while macOS keeps pinging until you press Ctrl + C. Use ping -c 4 on a Mac to get the same result as Windows.

Example 3: Find and stop the program using a port

Developers often see an error that a port such as 3000 is already in use. On Windows, find the process ID and stop it:

netstat -ano | findstr :3000
taskkill /PID 1234 /F

On macOS, do the same with:

lsof -i :3000
kill 1234

Replace 1234 with the real process ID shown in the first command. On macOS, try the plain kill first. Use kill -9 only if the program refuses to stop.

Handy commands that exist on only one system

  • macOS: open . opens the current folder in Finder, pbcopy and pbpaste work with the clipboard, caffeinate keeps the Mac awake, and softwareupdate -l lists available system updates.
  • Windows: start . opens File Explorer, clip copies output to the clipboard, winget installs software, and sfc /scannow checks system files when run as administrator.

Safety tips before you press Enter

  • Deleting from the command line is permanent. There is no Recycle Bin or Trash, so del, rmdir /s and rm -r cannot be undone.
  • List a folder with dir or ls before you delete it, to be sure you are in the right place.
  • Avoid disk tools such as format and diskpart unless you know exactly what they do.
  • Use administrator rights or sudo only when a task truly needs them.
  • Never paste commands from a website you do not trust. A single line can delete files or install malware.

Tips to work faster

Press Tab to complete file names and commands, and press the Up arrow to bring back earlier commands. Press Ctrl + C to stop a command that is still running. On both systems you can drag a file or folder into the window to paste its full path. When you forget an option, use help command on Windows or man command on macOS.

Summary

Windows CMD and macOS Terminal reach the same goals with different words: dir and ls, copy and cp, tasklist and ps, ipconfig and ifconfig. Learn the table above, practise on a test folder, and be careful with anything that deletes. Once you are comfortable, try connecting to servers with SSH keys, which works from both Windows and macOS, or read the cybersecurity roadmap for 2026 to see where these skills lead.
