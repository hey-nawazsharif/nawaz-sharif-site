- URL: https://cms-preview.nawazsharif.in/index.html
- Live public site: https://nawazsharif.in (still on GitHub Pages).
- Only / and /index.html on the preview have the redesigned sections.
- Deep navy editorial hero, CSS terminal illustration, restrained blue highlights and off-white service/article grids.
- Content focuses on Linux, IT support, networking, Python and ongoing cybersecurity learning; no invented professional roles or experience years.
- Original homepage Formspree contact form, Google reCAPTCHA markup, consent script, navbar, footer, and article URLs are retained.
- Homepage CMS fields remain respected when explicitly published; otherwise neutral preview copy is used.
- D1 article cards read published_snapshot, never draft metadata.
- Existing Visual Builder still works with main#main as before.
- All new CSS is scoped to body.ns-premium, leaving other pages unaffected.
- Preview robots disallow and X-Robots-Tag noindex remain.
- Mobile responsive and reduced-motion styles supported.

Review desktop/mobile appearance; confirm real contact form reCAPTCHA and cookie functionality; check article URLs, accessibility and SEO. Explicit approval needed before public domain routing changes. Automated tests verify presence of form/CAPTCHA markup, not an actual submission.
